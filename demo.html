    四种状态是什么意思？

    matched · 已匹配有同技能、已验证的项目或生产级证据。
    partial · 部分匹配有同技能、已验证的学习或练习证据。
    unverified · 待核实有相关描述，但证据尚未验证。
    missing · 缺少证据当前数据中没有同技能证据。
    边界说明：案例核对只检查这五个预设输入，不能证明任意岗位分析准确。“已验证”是输入标记，程序没有核实现实能力；本页没有身份验证，仅用于本机模拟演示。历史 API 示例仍可按 README 单独运行。
