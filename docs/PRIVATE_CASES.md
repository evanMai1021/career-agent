# 本机私有案例：终端与独立页面

这两个入口只读取本机调用者明确指定的、手工整理的脱敏 JSON。不解析原始 PDF，不扫描目录，不调用模型，也不写入案例或其他文件。终端入口运行后退出；独立页面入口启动只监听本机的服务，不改变原 `/demo` 或 `api_app.py` 的数据范围。

## 终端运行

在项目根目录打开 PowerShell，使用已安装依赖的项目虚拟环境：

```powershell
.venv\Scripts\python.exe -X utf8 private_case_runner.py --case-file "notes\my-private-case.json"
```

`my-private-case.json` 是示意文件名，仓库不提供或自动创建这份私人资料。请替换为你已手工整理、去除直接个人信息的 JSON 路径；不要传入原始简历、PDF、URL 或 `.env`。

报告在当前终端展示来源说明、资格声明、每项要求及其关联证据、可信事实、未关联的其他证据和局限。输入文件保持不变，执行结束后直接退出，不需要启动或停止服务。

如果需要机器可读输出：

```powershell
.venv\Scripts\python.exe -X utf8 private_case_runner.py --case-file "notes\my-private-case.json" --json
```

终端输出仍是私人资料，不应复制到公开日志、截图或仓库。程序不会自动导出文件；用户自行使用终端重定向产生的文件也需按私人资料管理。

退出码：`0` 表示正常分析且预设未配置或核对通过；`1` 表示分析完成但与人工预设不符；`2` 表示输入或执行失败。没有预设时明确显示“未核对”，不能把退出码 `0` 当作能力验证、候选人评分或招聘通过。

## 独立私有页面运行

使用现有项目依赖，无需密钥或安装新依赖。在项目根目录打开 PowerShell：

```powershell
.venv\Scripts\python.exe -X utf8 private_case_server.py --case-file "notes\my-private-case.json" --port 8001
```

保持终端开启，在浏览器打开 `http://127.0.0.1:8001/private`，不要将地址改为 `localhost` 或其他主机名。先检查来源、资格声明、岗位要求及本次输入的全部证据，再点击“分析这份资料”。页面展示执行情况、人工预设核对、每项要求的关联证据和可信事实；无关证据仍单独展示。没有预设时显示“未核对”，缺少证据不代表程序失败或现实中不会。

这是整理后的输入，不是原始简历全部栏目。服务启动后固定使用一份内存快照；“重新加载资料”只重新读取该快照。修改 JSON 后，先在终端按 `Ctrl+C` 停止并重新启动，再刷新页面。结束使用时按 `Ctrl+C` 并关闭私有页面。若 8001 已被占用，不要关闭未知进程，可改用 `--port 8002`，同时访问对应的 `http://127.0.0.1:8002/private`。

页面没有上传、编辑、保存或导出功能；不会自动寻找私人文件。启动时须明确指定文件，没有全局私有应用或默认案例。浏览器只提交当前快照标识，不接受客户端指定文件路径、模型或输出位置。断连、超时或结果与输入不一致时隐藏旧结果，恢复服务后可重试。

### 页面访问边界

启动器固定监听 `127.0.0.1`；服务检查本机连接、精确主机和同源标记，拒绝代理转发头、查询参数及跨站请求。私有数据请求附带固定请求头，这只是浏览器请求约定，**不是身份验证或秘密凭证**；快照标识也不是认证令牌。同机其他程序仍可以读取资料，不适合共享电脑、公网、代理或端口转发环境。

页面不引入外部资源；响应禁止缓存和嵌入，启动器关闭访问日志。这些措施不保证完全隐私，也不能防止同机程序、截图、终端或浏览器进程泄露资料。只能使用手工脱敏资料；不要加入密钥、联系方式或其他高敏感信息，不把此服务当作真实候选人管理系统。

## 输入约定

必需字段：

- `case_id`：小写字母开头，仅含小写字母、数字、下划线，最长 80 字符。
- `data_kind`：真实来源脱敏草案使用 `real_source_sanitized_draft`；纯人工测试资料使用 `synthetic_private_test`。
- `job`：与现有 `job_data.validate_job` 约定相同，包含 `job_id`、`title` 和非空 `requirements`。
- `candidate`：与现有 `job_data.validate_candidate_evidence` 约定相同，包含 `username` 和 `evidence`。岗位 ID 与用户名也使用上述标识格式；格式检查不保证匿名。

可选字段：

- `notice`：非空说明。
- `source_metadata`：只接受 `jd`、`resume` 两类来源。JD 可记录 `kind`、`collected_at`、`company`、`posting_date`、`url`、布尔值 `origin_verified`、`interpretation_note`；简历可记录 `kind`、正整数 `pages`、`file_modified_date`、布尔值 `content_independently_verified`、`privacy`。其他字段须为非空文本或 `null`。这里的标记是输入声明，不是程序验证来源。
- `qualifications`：独立资格声明列表；每项必须包含 `qualification_id`、`required`、`declared`、`source`、`verification`、`note`，均为非空文本。本入口只接受 `verification=unverified`，不自动证明学历、届别或录用资格。
- `expected`：可省略。如果设置，必须包含 `execution_status=completed` 和 `states`；可附非空 `note`。`states` 按岗位要求顺序覆盖每个 ID，状态只允许 `matched`、`partial`、`missing`、`unverified`。预设必须在运行前人工确定，不调用生产函数生成。

字段遗漏、额外字段、非法类型、重复 JSON 字段、非有限数值、超过 2 MiB 的文件或命中常见敏感格式会被拒绝。错误信息不回显输入内容或本机路径。

全部文本及字段名还须能编码为 UTF-8；孤立 Unicode 代理字符会被安全拒绝。为避免终端显示被控制序列改写，拒绝 ESC、DEL、C1 等控制字符及单独的 CR；保留中文、正常表情、制表符、LF 和完整 CRLF 换行。拒绝不会自动替换原文或修改输入文件；两个入口使用同一项校验，在分析或启动服务前返回安全错误。

## 能说明什么

- 同一输入快照用于校验、匹配、可信事实和结果展示；不会根据简历自动升级 `verified`。
- 已配置预设时，核对包括执行、完整匹配和完整可信事实。预期输出从原始输入与人工状态构造，不调用生产匹配或事实函数；事实缺失、证据 ID 错误、额外自由文本或结构不一致会导致执行失败。
- 缺少证据仍可正常完成分析；`missing` 不等于现实中不会。无关技能记录保留展示，不替代岗位所缺的技能。
- 学历、毕业届别等资格声明单独展示，不计入技能四态，也不自动判断是否符合招聘资格。

## 隐私与能力边界

私人输入放入 Git 已忽略的 `notes/`，原始 PDF 和个人联系方式不要复制到项目。公开代码、说明和自动化测试不依赖私人文件；测试只使用人工构造的资料。

程序复用有限格式扫描，识别常见电话、邮箱、本地路径和令牌。它不识别所有隐私形式，不能证明材料完全匿名或适合公开。姓名、学校、单位、照片和能组合识别身份的信息仍需人工处理；禁止把扫描通过解释为公开授权。

这些入口不是简历自动解析器、自然语言技能推断、真实模型评估或公网候选人服务。原网页 `/demo` 与现有公开演示 HTTP 接口不读取此私人案例。

## 测试

```powershell
.venv\Scripts\python.exe -m unittest test_private_case_runner test_private_case_server
```

23 项终端入口测试和 22 项私有服务测试覆盖四态、同一快照、不变性、声明不升级、完整预设、共享错误检测、事实隔离、资格分离、敏感格式、错误处理、命令行退出码及本机访问边界。新增反例验证异常 Unicode 与终端控制字符在分析或服务启动前被拒绝，错误不回显原文、路径或异常堆栈；正常中文、表情和常见换行可完整保留。另有 13 项私有页面脚本测试，覆盖快照一致性、完整事实、重复点击、断连、超时、重试和文本安全展示。

私人文件未提供时，这些人工资料测试仍应通过；包含私有入口的完整 Python 回归为 240 项。原演示页 30 项与私有页 13 项脚本测试合计 43 项，可用已安装的 Node.js 执行：

```powershell
node --test test_demo_page.cjs test_private_demo_page.cjs
```

这些结果只证明指定人工案例和边界的回归，不证明任意 JD、真实模型准确率或简历声明的真实性。
