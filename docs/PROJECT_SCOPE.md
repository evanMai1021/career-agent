# CareerAgent 当前公开版本范围

## 已包含

V1.7 的定位是人工脱敏结构化资料的本机只读分析；原模拟与历史视图保留。真实来源声明的输入与规则核对，不等于现实能力核实或真实招聘评估完成。

- LLM 结构化输出
- 至少 2 个被受控 Agent 流程实际调用过的工具；写入工具必须经过参数预览和用户确认
- 受控 Agent 循环
- 本地状态保存
- 自动化测试
- 脱敏固定案例、离线评估夹具、批量指标、案例筛选和可选的独立 JSON 报告
- 由 Python 确定性匹配和结构化证据生成的 `trusted_facts`，以及模型生成内容的未验证来源标记
- 包含案例分类、计数指标、复现命令和局限说明的 V1.2 脱敏评估报告
- 固定读取脱敏项目数据的 FastAPI 本地只读服务
- 展示五个固定模拟输入、证据来源、判定原因及预期／实际对照的本机 `/demo` 页面
- 原演示服务的健康检查、岗位要求查询、默认离线确定性分析、本机演示页、模拟案例目录与案例分析、历史用户资料七个 HTTP 接口
- 固定 `test_user` 的完整历史演示字段视图，包含目标岗位、全部证据、学习进度和复习任务
- 本机调用者明确指定脱敏 JSON 的独立只读终端入口，不扫描目录、调用模型或写文件
- 可直接运行的纯虚构 JSON 模板与脱敏填写说明，覆盖四态及未关联证据，不提供或公开个人资料
- 独立本机文件文字导入与人工校对页，支持文字型 PDF、UTF-8 TXT 及 DOCX 正文／表格，不连接岗位分析、不保存文件或草稿
- 默认关闭的可选千问 JSON 整理：明确同意外发后的修正文字、待复核字段、缺项 null、全部证据 false 及本地复验；离线响应替身验证，不代表真实格式化联调完成
- 独立私有服务的页面、快照读取、快照分析三个接口；不让原演示服务自动读取私人文件
- 同一份输入的岗位要求、来源、全部证据、匹配与可信事实展示，独立资格声明及未关联证据展示，可选完整人工预设核对
- 异常 Unicode 与终端控制字符的安全拒绝，以及私有服务本机访问边界、快照一致性、超时和重试的反例测试
- 与默认 API 实际响应逐字段一致的 V1.3 脱敏示例
- API 空白值、错误字段类型和缺失服务端文件的边界测试
- 模型不可用时保留 Python 确定性岗位匹配结果
- README 与一张脱敏的代表性运行截图
- 项目主张到代码、测试和演示证据的公开映射，以及技术决策、修复案例和讲解材料

## 未包含

- RAG
- 多 Agent
- 带登录或真实候选人数据的公网网页应用
- 自动岗位搜索
- 自动投递
- 云部署
- 扫描件 OCR、旧式 DOC、完整 Word 排版还原、经真实验收的任意 JD 理解或无需人工复核的技能映射
- 现实能力鉴定、自动学历或届别验证、候选人评分或录用决策

## 范围约束

- 公开功能必须有代码、实际运行或自动化测试证据支持。
- 未包含的功能不得出现在简历亮点、README 功能清单或运行证据中。
- LLM 与写入操作继续遵守工具白名单、参数校验、用户确认和磁盘回读边界。
- 自动化测试结果、数据质量检查和 GitHub 安全检查使用可复核的文字或命令输出记录即可，不为每项结论单独截图。
- V1.2 评估结果只适用于当前固定脱敏案例和模型响应替身，不得宣传为真实模型的普遍准确率或完整红队测试结论。
- 原演示 API 只在本机固定脱敏数据范围内完成验证，不得宣传为已支持任意 JD、真实候选人数据、公开联网服务或生产部署。
- 原演示 API 与独立私有服务均没有身份验证，只应按运行说明监听 `127.0.0.1`；原服务不用于真实候选人数据，私有入口仅接受人工脱敏资料，二者均不用于公网或共享电脑。
- 私有资料只由本机启动调用者明确指定，HTTP 客户端只提交快照标识，不能提交文件路径、岗位、候选人或模型。固定请求头与快照标识不是认证，同机其他进程可读；不使用代理或端口转发。
- 私有入口不自动提升验证标记、不判断录用资格，也不完整复刻原始简历栏目。私人文件与截图不得因为格式扫描通过就公开。
- `/demo` 只调用同源的模拟案例接口；案例由服务端白名单控制，客户端不能提交任意岗位、候选人、证据、文件路径或模型。
- 原演示案例及公开自动化测试使用人工输入，不冒充真实个人能力；本机私有输入可包含脱敏后的真实来源声明，但仍需人工核实。原历史 JSON 保留为回归数据，不根据当前代码完成情况自动提升验证标记。
- 历史资料视图只显示固定用户的已有演示字段，不返回其他用户或额外未约定字段；学习进度不自动转化为已验证能力。历史用户资料与模拟案例输入分别呈现。
- 分析执行状态与案例核对分开；核对完整匹配与可信事实，不能只凭相同状态宣称通过。输入拒绝报告可通过预设核对，缺少证据也可完成分析。HTTP 200 不能代替报告内的执行状态。
- `POST /analyses` 只运行 Python 确定性分析；`model_generated=false` 不得解释为项目所有分析流程均不使用模型。
- 结构化虚构内容接受率只覆盖伪造要求 ID 和证据 ID；自由文本指标只检查案例明确配置的禁止声明，不代表完整语义幻觉检测或产品已阻止虚构。
- 可信事实自由文本泄漏 `0/4` 只证明四个适用固定案例中的已知声明未越界，不能表述为模型已经停止产生幻觉。
- 案例、夹具和报告的隐私扫描只识别常见格式，不能替代人工脱敏检查。
- 项目证据页仅支持介绍仓库中的功能；个人独立贡献、闭卷讲解水平与简历表述仍需另行核对。
