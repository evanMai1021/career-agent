# V1.9.3：一条命令启动本机服务

统一启动器只管理现有独立服务，不增加统一首页、跨页导航、资料同步或保存功能。原三个服务及其单独启动方式保持不变；不把不同页面的数据自动混用。

## 默认启动：演示页与文件导入页

在项目根目录 PowerShell 中运行：

```powershell
.venv\Scripts\python.exe -X utf8 start.py
```

无需密钥，默认关闭模型整理。等待终端显示“本次服务均已就绪”后，分别打开：

- 演示页：`http://127.0.0.1:8000/demo`
- 文件导入页：`http://127.0.0.1:8002/import`

终端会显示“私有资料页：未配置，未启动”；不会寻找或自动读取私人文件，不会自动打开浏览器。选择文件、模型整理和确认分析仍在对应页面中人工操作。

## 同时启动三个页面

先使用仓库的纯虚构模板：

```powershell
.venv\Scripts\python.exe -X utf8 start.py --case-file examples/careeragent_v1_7_private_case_template.json
```

在前两个地址之外，私有资料页为 `http://127.0.0.1:8001/private`。这里展示的是虚构资料，不是个人能力证明。只有自己已准备好手工脱敏 JSON 时，才把 `--case-file` 换成明确指定的本地文件；不要传原始简历、PDF、URL 或密钥文件。私有页沿用原启动快照，不读取导入页的新草稿。

## 端口被占用时

端口不可用会停止启动并说明服务名称和端口，不关闭或接管已有服务。可改用其他未占用端口：

```powershell
.venv\Scripts\python.exe -X utf8 start.py --demo-port 8010 --import-port 8012 --private-port 8011 --case-file examples/careeragent_v1_7_private_case_template.json
```

对应地址为 `http://127.0.0.1:8010/demo`、`http://127.0.0.1:8012/import`、`http://127.0.0.1:8011/private`。已启用服务的端口不能相同；允许范围为 1 到 65535。不要为了启动本项目结束未知进程。

## 可选模型整理

只有确实需要把校对文字交给已有千问服务时，才添加开关：

```powershell
.venv\Scripts\python.exe -X utf8 start.py --enable-model-format
```

启动开关本身不调用模型，仍须本地配置已有密钥、人工校对并在导入页另行勾选外发同意和点击生成；实际调用可能产生费用。默认提取和本机规则分析不需要密钥。启动器不读取密钥、不在终端展示子进程原始异常或私人文件路径。详见 [文件导入说明](FILE_IMPORT.md)。

## 停止、失败与边界

- 保持一个终端开启，按 `Ctrl+C` 请求一起停止本次启动的服务。启动器先通过内部管道请求正常退出；超时后也仅终止自己记录的子进程，不扫描或按端口、名称批量关闭进程。
- 启动等待上限为 20 秒；只有工作进程完成应用启动与绑定后才发送就绪标记。启动预检查后的端口竞争仍可能导致失败，但不会通过探测到其他服务而误报本次成功。
- 任一服务启动失败、超时或运行中退出，会回收本次其他服务并返回失败，不展示为全部可用。错误只说明服务与类别，不转发底层日志；需要人工检查端口、脱敏 JSON 或本地环境后重试，不自动重复启动。
- 退出请求会等待服务结束；处理中的解析工作仍受原解析限时约束。父进程管道断开也会请求子服务退出，但不是完整的进程沙箱或系统故障恢复保证。
- 仅监听 `127.0.0.1`，无身份验证，不用于共享电脑、公网、代理或端口转发。统一启动不削弱原私有／导入服务的同源和固定请求约束。
- 不自动分析、保存、升级验证标记或共享草稿。停止服务不保存当前草稿；刷新／清空／关闭页面仍沿用原有丢失草稿的边界。

## 实现与验证

根入口为 [start.py](../start.py)，进程管理在 [start_services.py](../career_agent/cli/start_services.py)，内部工作进程在 [managed_worker.py](../career_agent/services/managed_worker.py)。没有新增依赖；工作进程使用启动器当前的 Python 解释器，工作目录固定到项目根。

```powershell
.venv\Scripts\python.exe -X utf8 -m unittest tests.test_start_services
```

新增 25 项测试覆盖默认无私有文件／模型、明确开关、参数与端口冲突、就绪与超时、部分失败回收、运行退出、信号恢复、正常／强制退出范围、错误不回显和父管道 EOF。真实本机 HTTP 测试使用临时端口和公开虚构模板，验证两页／三页可访问、默认模型关闭、错误资料回滚和端口释放。

完整 355 项 Python、121 项网页脚本通过。另在真实终端一次启动三个页面，均返回 HTTP 200，Ctrl+C 后三个验收端口无监听；没有真实模型调用、浏览器交互或真实资料验收。这只证明约定本机流程，不代表公网或生产部署能力。
