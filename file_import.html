1. 选择虚构或脱敏文件

支持文字型 PDF、UTF-8 TXT、Word DOCX，最多 2 MiB。旧式 DOC 请先另存为 DOCX。

尚未导入文件。

文件只发送到本机服务，不上传云端、不默认保存原件。无身份验证，同机其他进程可能访问；不用于共享电脑、公网、代理或端口转发。不要在此导入未经脱敏的真实简历。

2. 对照原文并修正
