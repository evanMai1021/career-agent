本机文件文字导入

选择文件 → 提取原文 → 对照原件并人工修正。这里只预览文字，不进行岗位分析，不验证能力。

1. 选择虚构或脱敏文件

支持文字型 PDF、UTF-8 TXT、Word DOCX，最多 2 MiB。旧式 DOC 请先另存为 DOCX。

尚未导入文件。

文件只发送到本机服务，不上传云端、不默认保存原件。无身份验证，同机其他进程可能访问；不用于共享电脑、公网、代理或端口转发。不要在此导入未经脱敏的真实简历。

2. 对照原文并修正

“原提取文本”保持不变；修改框只是本页的校对草稿，来源位置指向提取前的页／行／正文结构，不是修改后文字的证明。

    发送内容是当前修正框和补充框的文字，不是原文件。最多 12000 个字符。千问是外部服务，原文件不发送；请先删除姓名、联系方式、公司／学校等不必要信息。有限格式扫描不能保证完全匿名。

    未校对。文本及声明均待核实，未产生匹配结果。

    本页已成功生成过 JSON。再次生成会重新发送当前校对文字，可能再次产生 API 费用，并替换当前 JSON 草稿（包括手动修改）。取消可保留草稿；仅校验 JSON 不调用模型。

    4. 校对模型生成的 JSON

    技能标识、层级、要求类型及优先级都是模型提议，须逐项核对。所有证据 verified=false，资格仍待核实；缺少岗位或候选人时为 null，不能直接用于原分析入口。

      不自动保存、复制、下载或分析。完整草稿通过结构校验后，仍须你核对内容，再手动保存到已忽略的 notes 目录；这不会自动改变原分析页的启动快照。

      刷新、清空或关闭会丢失本页草稿。“校对确认”“JSON 结构通过”都不等于能力或来源核实。
